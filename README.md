# ZDT-RoboticArm

基于 STM32F407VET6、张大头 Emm 闭环步进驱动器和 MG90S 夹爪舵机的四轴机械臂控制项目。

当前版本已经完成关节空间底层控制链路和配套上位机：F407 负责四轴电机总线、状态反馈、安全检查及舵机 PWM；PC 上位机负责连接、单轴控制、连续点动、置零、急停、轨迹示教和夹爪舵机控制。

## 当前版本状态

- F407 下位机工程已纳入 Keil 工程并可完整构建。
- 张大头 Emm 固件四轴驱动、位置控制、连续速度控制和状态轮询已接通。
- 上位机协议、应答和四轴遥测链路已接通。
- 上位机支持按住正向/反向连续运行；松开按钮发送 0 速度停止，但不进入急停锁定。
- 红色停止按钮和全局急停仍然是锁定式急停，需重新使能或按现有流程解除。
- MG90S 夹爪舵机控制已加入，角度范围 0~180°，支持闭合、中位、打开快捷位置。
- 上位机中间数字孪生/虚拟编码器区域已移除，控制卡和轨迹、遥测区域重新布局。
- 当前代码和静态构建验证完成；真实机械行程、负载、舵机方向和供电仍需上电实测。

## 轴和通信分配

| 轴 | Emm 地址 | 机械部分 |
| --- | ---: | --- |
| 1 | 1 | 底部丝杆轴 |
| 2 | 2 | 底座旋转轴 |
| 3 | 3 | 大臂关节 |
| 4 | 4 | 小臂关节 |

- USART1：PA9/PA10，115200 8N1，连接四台张大头 Emm 驱动器。
- USART2：PA2/PA3，115200 8N1，经 DAP-Link 连接 PC 上位机。
- 舵机：TIM3_CH1 输出到 PA6，50 Hz PWM，默认脉宽 500~2500 us 对应 0~180°。

舵机必须使用独立稳定的 5 V 供电，并与 F407 共地；不要从 F407 3.3 V 直接给 MG90S 供电。PA6 是当前工程约定的舵机信号脚，实际接线前请核对 PCB 和线束。

## 下位机主要模块

| 模块 | 作用 |
| --- | --- |
| `MotorBus` | 四轴状态、安全门、Emm 命令排队、反馈解析和超时检测 |
| `HostProtocol` | USART2 上位机帧解析、ACK 和四轴状态遥测 |
| `Servo` | MG90S 50 Hz PWM 和 0~180°角度映射 |
| `ArmControl` | 板载按键、编码器、OLED 菜单和本地控制 |
| `Encoder` / `Key` | 四路 EC11 与六路按键输入处理 |
| `OLED` | 本地状态和安全提示显示 |
| `Emm_V5` | 张大头厂商协议接口，保持原协议实现 |

## 上位机

源码入口：`机械臂控制上位机/main.py`

已打包程序：`App/机械臂控制上位机/机械臂控制上位机.exe`

上位机包含四轴独立控制卡、速度/加速度设置、按住连续点动、单轴置零、急停、轨迹示教/执行、通信日志、四轴遥测和 `GRIPPER SERVO` 夹爪控制卡。舵机角度通过 HostProtocol 的 `0x08` 命令发送，载荷为一个 0~180 的角度字节。

## 上电和安全流程

1. 无负载或使用机械支撑固定机械臂。
2. 确认四台驱动器地址为 1~4、波特率为 115200。
3. 上电确认四轴在线，先完成当前位置置零。
4. 零点有效后再使能电机，首次运动逐轴低速测试。
5. 连续点动时，按住按钮运行，松开按钮停止但不锁定；真正急停使用红色停止按钮或全局急停。
6. 舵机首次测试使用中位或较小角度，确认机械夹爪没有顶死后再测试端点。

当前 `±180°` 是步进轴的初始软件范围，不代表真实机械安全行程；MG90S 的 0°和 180°也不应在未确认连杆极限前直接使用。实际设备仍应增加实体限位、独立硬件急停和重力轴支撑/制动措施。

## 后续工作边界

底层驱动和上位机控制链路已经具备继续联调的条件。后续重点是实机标定：四轴正方向、传动比、真实软限位、Emm 驱动器参数、舵机脉宽范围、供电和机械夹爪开合方向。ROS、逆运动学和自动轨迹应在这些硬件检查完成后再接入。
