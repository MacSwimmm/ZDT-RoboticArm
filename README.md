# ZDT-RoboticArm

基于 STM32F407VET6 和张大头 ZDT X42S 闭环步进电机的四轴机械臂控制项目。

仓库当前包含机械臂下位机固件；后续计划在同一仓库中增加上位机、ROS 接口、运动学解算和轨迹规划。现阶段重点是可靠完成关节空间底层驱动、多电机反馈、人工零点确认、软件限位以及本地人机交互。

## 当前功能

- STM32F407VET6 下位机，主频 168 MHz
- USART1 控制四台 Emm 固件 ZDT 闭环步进电机
- 电机地址 1～4 独立轮询、反馈解析和超时检测
- 四个 EC11 编码器分别调节四个机械轴
- 编码器支持角度、位置命令速度和加速度三种调节模式
- SSD1306 128×64 I2C OLED 菜单与实时状态显示
- OLED 短超时、断线重试和 I2C 总线恢复
- 六个独立按键，支持软件消抖、短按和长按
- 人工零点确认、±180°初始软件限位、停止锁定和失能保护
- 快速旋转编码器时合并同一轴的最新位置目标
- USART1 DMA 接收和四轴命令串行调度

## 电机地址分配

| 轴 | ZDT 地址 | 机械结构 |
| --- | ---: | --- |
| 1 | 1 | 底部丝杆轴 |
| 2 | 2 | 底座旋转轴 |
| 3 | 3 | 大臂轴 |
| 4 | 4 | 小臂轴 |

USART1 使用 PA9/PA10，通信参数为 115200、8N1。四台驱动器必须提前分别设置为地址 1～4，并确认实际接口支持可靠的 TTL 多机拓扑。不得直接并联多个普通推挽 TX；必要时应增加 RS485 物理层或拆分总线。

## 上电与安全流程

上电后固件不会让机械臂自动运动，并会排队发送四轴失能命令。

1. 无负载或使用机械支撑固定机械臂。
2. 逐台确认电机地址和 115200 波特率。
3. 确认 OLED 显示四台电机在线。
4. 手动把机械臂移动到选定的安全参考姿态。
5. 在零点页面逐轴确认零点，或确认全部轴。
6. 四轴零点全部有效后，才能执行全部使能。
7. 首次运动必须逐轴、低速、无负载验证。

当前版本尚未安装实体限位开关，也没有自动碰撞回零功能。±180°只是初始软件范围，必须根据真实机械行程重新标定。重力负载轴在失能后可能下坠，实际设备应增加机械支撑、制动、自锁传动或配重，并保留独立硬件急停。
